# ArcBridge

A full-stack multi-chain bridge dApp with a baby pink Web3 design system, chain switching, referral engine, rewards dashboard, and global analytics.

## Tech Stack

- Frontend: Next.js, React, Tailwind CSS
- Web3: Wagmi, Viem, RainbowKit
- Smart contracts: Solidity, Hardhat
- UI motion: Framer Motion
- Icons: Lucide React

## Included

- Bridge widget for source/target chain selection
- token transfer UX and recipient address
- fee and gas breakdown card
- faucet CTA
- referral hub with 10% lifetime points bonus
- activity history and leaderboard
- analytics summary cards
